
# University Assignment Manager

A Python command-line application for managing university assignments

## Features

- Add new assignments
- Prevent duplicate assignment titles
- Mark assignments as completed
- Display pending assignments
- Count unfinished assignments
- Save and load assignments using JSON
- Handle missing or invalid JSON files

## Requirements

- Python 3
- No external libraries required

## How to Run

From the root of the repository:

bash
python "small projects/assignment_manager.py"


## Menu

1. Show pending assignments
2. Add assignment
3. Complete assignment
4. Number of pending assignments
5. Save and exit

## Data Storage

Assignments are stored in `assignments.json`.

The program loads saved assignments when it starts and saves changes when the user selects "Save and exit"

## Technologies

- Python
